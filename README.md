# דף נחיתה – רמקול שיירת האור (חנוכה)

דף נחיתה סטטי (HTML/CSS/JS בלבד, ללא שרת).
ההזמנות נשלחות ישירות לטופס הגוגל של המארגן, ומשם לגיליון התשובות שלו.

## קבצים
- `index.html` – הדף עצמו
- `assets/img/` – תמונות (זמניות, מ-Unsplash)
- `preview/levi-speaker-landing.html` – עותק בקובץ אחד, עם התמונות מוטמעות, לשליחה ולצפייה
- `preview/*.jpg|png` – צילומי מסך לתצוגה מקדימה

## חיבור לטופס הגוגל
בראש הסקריפט ב-`index.html` מוגדרים `GOOGLE_FORM_ACTION` ומזהי השדות (`entry.*`).
אם מוסיפים, מוחקים או משנים שאלות בטופס הגוגל, צריך לעדכן גם את המזהים כאן.

## החלפת תמונות
מחליפים את הקבצים ב-`assets/img/` בקבצים באותו שם, או משנים את הנתיבים ב-`index.html`.

## פרסום
אפשר לפרסם בחינם ב-GitHub Pages (Settings → Pages → Branch), ב-Netlify או ב-Vercel.
