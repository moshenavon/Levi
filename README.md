# דף נחיתה – רמקול שיירת האור (חנוכה) · גרסת חב"ד לוד

> ענף `lod`: גרסה לקהילת חב"ד לוד. מחיר 300₪ ליח', בלי מינימום הזמנה, בלי טיימר, בלי משלוח חינם ובלי שיתוף בוואטסאפ. ההזמנות נשלחות לטופס הגוגל של לוד. הלוגואים: `assets/img/logo-770-lod.webp`, `assets/img/logo-kehila-lod.webp`.
> האתר הראשי נמצא בענף `claude/hanukkah-speaker-landing-smtdkg`.

דף נחיתה סטטי (HTML/CSS/JS בלבד, ללא שרת).
ההזמנות נשלחות ישירות לטופס הגוגל של המארגן, ומשם לגיליון התשובות שלו.

## קבצים
- `index.html` – הדף עצמו
- `assets/img/` – תמונות המוצר (מתיקיית הדרייב) בגרסאות WebP בכמה גדלים, ורקע החנוכייה מ-Unsplash
- `assets/video/` – סרטוני המוצר (demo-1..4.mp4) ותמונות הפתיחה שלהם (demo-1..4.webp)

## חיבור לטופס הגוגל
בראש הסקריפט ב-`index.html` מוגדרים `GOOGLE_FORM_ACTION` ומזהי השדות (`entry.*`).
אם מוסיפים, מוחקים או משנים שאלות בטופס הגוגל, צריך לעדכן גם את המזהים כאן.

## החלפת תמונות
מחליפים את הקבצים ב-`assets/img/` בקבצים באותו שם, או משנים את הנתיבים ב-`index.html`.

## פרסום
אפשר לפרסם בחינם ב-GitHub Pages (Settings → Pages → Branch), ב-Netlify או ב-Vercel.
